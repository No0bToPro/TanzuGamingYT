# @TanzuGamingYT - Valorant Personal Website

A modern, Valorant-themed personal website for gaming YouTuber @TanzuGamingYT.

## Features

- **Valorant-inspired Design**: Dark theme with red accents (#ff4655) and futuristic styling
- **Responsive Layout**: Works perfectly on desktop, tablet, and mobile devices
- **Interactive Animations**: Glitch effects, hover animations, and smooth transitions
- **Modern Typography**: Uses Rajdhani and Orbitron fonts for a gaming aesthetic
- **Social Media Integration**: Links to YouTube, Twitch, Discord, and Instagram
- **Performance Optimized**: Smooth animations with throttled scroll events

## Sections

1. **Hero Section**: Eye-catching introduction with animated background
2. **About Section**: Personal info with gaming statistics
3. **Latest Videos**: YouTube video showcase with hover effects
4. **Highlight Moments**: Gaming achievements and epic plays
5. **Contact Section**: Social media links and connections
6. **Footer**: Copyright and branding

## Technologies Used

- **HTML5**: Semantic structure and accessibility
- **CSS3**: Advanced styling with animations and responsive design
- **JavaScript**: Interactive elements and smooth user experience
- **Font Awesome**: Social media icons
- **Google Fonts**: Rajdhani and Orbitron typography

## Getting Started

1. Open `index.html` in your web browser
2. No additional setup or dependencies required
3. All files are self-contained and ready to use

## Customization

### Colors
The website uses CSS custom properties for easy color customization:
- `--primary-red`: Main accent color (#ff4655)
- `--secondary-red`: Secondary accent (#ff6b7a)
- `--dark-bg`: Background color (#0f0f0f)

### Content
- Update social media links in the HTML
- Replace placeholder video content with actual YouTube embeds
- Modify personal information in the About section
- Add real gaming statistics and achievements

### Animations
- Adjust animation speeds in CSS
- Modify glitch effects in JavaScript
- Customize hover effects and transitions
